# ADR-001 リポジトリを公開のまま運用する

更新日：2026-11-26
前提資料：資料01 企画書（8.4）

| 項目 | 内容 |
|---|---|
| 状態 | 決定 |

| 関係する作業・資料 | T01（#2）、資料01 企画書 8.4（#59） |

## 背景

正本の GitHub リポジトリ（t41g4/RE-A12）は公開で作られていた。公開だと、メンバー名や資料の中身を誰でも読める。T01 で、非公開にするかを検討した。

## 決めたこと

- リポジトリは**公開のまま**にする。
- 編集（プッシュ）できるのは、招待したメンバーだけにする。
- 本名・連絡先などの個人情報や、外に出せない情報は書かない。

## 検討した案

| 案 | 良い点 | 弱い点 |
|---|---|---|
| 公開のまま（採用） | 追加の費用がない。ブランチ保護（main への直接の書き込みを禁止する設定）も無料で使える | 誰でも読める。GitHub のアカウントがあれば、メンバー以外も Issue やコメントを書き、自分のコピーからプルリクエストを送れる |
| 非公開にする | メンバー以外は読めない | 無料プランではブランチ保護が使えない【事実】。メンバー全員をコラボレーターとして招待する必要がある |

## 決めた理由

- 招待したメンバーだけが編集できれば、公開でも問題ないと判断した。

## 影響・注意点

- 個人情報や外に出せない情報を書かないルールを、CLAUDE.md と claude.ai のプロジェクト指示に入れた。
- 対象事業者の調査（T03）は公開情報と想定で整理する前提なので、公開でも書ける範囲に収める。
