# ADR-005 claude.ai プロジェクトに資料の写しを置かない

更新日：2026-11-26
前提資料：資料01 企画書（8.4）

| 項目 | 内容 |
|---|---|
| 状態 | 決定 |

## 背景

正本は GitHub だが、claude.ai プロジェクトにも資料の写し（企画書・資料体系一覧）を置いていた。写しを誰がいつ更新するかが決まっておらず、GitHub と食い違うおそれがあった。

## 決めたこと

- claude.ai プロジェクトには、資料の写しを置かない。
- 置くのは、旧仕様書（PROJECT_SPEC 第5版）と資料体系一覧だけにする。
- Claude は、資料を GitHub から読む。
- これに合わせて、claude.ai プロジェクトにあった企画書の写しを削除した（2026-11-26）。

## 検討した案

| 案 | 良い点 | 弱い点 |
|---|---|---|
| 写しを置かず、GitHub から読む（採用） | 二重管理がなくなる | GitHub につながっていない普通のチャットでは資料を読めない |
| main に取り込んだ人が、そのつど写しも更新する | 写しが古くなりにくい | 毎回の手間が増え、忘れやすい |
| 進行管理（kei）が定例でまとめて更新する | 担当がはっきりする | 最大で数日古い写しを Claude が読むことがある |

## 決めた理由

- 二重管理をなくし、GitHub と食い違わないようにするため。

## 影響・注意点

- 資料体系一覧だけは写しが残る。GitHub 側で一覧を変えたときに、claude.ai の写しを誰がそろえるかは【未定】（資料04 課題・リスク管理表に載せる候補）。
- 資料を読む会話では、GitHub につながっている必要がある。
