# ADR-002 メンバーは main に直接プッシュし、Claude はプルリクエストで変更する

更新日：2026-11-26
前提資料：資料01 企画書（8.4）、ADR-001

| 項目 | 内容 |
|---|---|
| 状態 | 決定 |
| 決めた日 | 2026-11-26 |
| 関係する作業・資料 | T01（#2）、資料01 企画書 8.4（#59） |

## 背景

資料はリポジトリに Markdown で置き、メンバーと Claude の両方が更新する。確認を通してから main に取り込むか、直接書き込むかを決める必要があった。

## 決めたこと

- **メンバー**は、main に直接プッシュしてよい。
- **Claude** は main に直接プッシュしない。ブランチを作ってプルリクエストにし、メンバーが確認してから取り込む。
- Claude のブランチ名は、資料なら `docs/資料番号-内容`、作業なら `work/T番号-内容` とする。
- ブランチ保護は設定しない。Claude のルールは CLAUDE.md と claude.ai のプロジェクト指示に書いて守る。

## 検討した案

| 案 | 良い点 | 弱い点 |
|---|---|---|
| メンバーは直接、Claude だけプルリクエスト（採用） | メンバーの手間が増えない。Claude の変更は必ず人が確認する | メンバーの変更にはレビューの記録が残らない |
| 全員がプルリクエスト | レビューと履歴が残る | 手間が増える |
| 全員が直接プッシュ | 速い | Claude の変更も確認なしで正本に入る |

## 決めた理由

- メンバーの直接プッシュは許容できるが、Claude の変更だけは確認したいため。

## 影響・注意点

- ブランチ保護を使っていないので、Claude のルールは仕組みでは強制されない。CLAUDE.md とプロジェクト指示に書いて運用で守る。
- 資料の承認は ADR-004 のルールで行う。
